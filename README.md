6502 CPU Emulator

A MOS 6502 CPU emulator written in C++.

This project explores the fundamentals of CPU emulation, including registers, memory, instruction decoding, execution, and processor flags.

Features

* Language: C++
* Memory: 64 KB address space
* Registers: Accumulator (A), X, Y, Program Counter (PC), and Stack Pointer (SP)
* Status flags: Carry, Zero, Interrupt Disable, Decimal, Break, Overflow, and Negative
* Instruction execution: Fetch and execute supported opcodes
* Build system: CMake

Implemented Instructions

The current implementation includes a subset of 6502 instructions, such as:

Instruction	Description
LDA	Load accumulator
LDX	Load X register
LDY	Load Y register
STA	Store accumulator
STX	Store X register
STY	Store Y register
ADC	Add with carry
INX / INY	Increment index registers
DEX / DEY	Decrement index registers
TAX / TAY	Transfer accumulator to index register
TXA / TYA	Transfer index register to accumulator
NOP	No operation
BRK	Break instruction

Instruction support and behavior are still under development.

Getting Started

Requirements

* A C++ compiler
* CMake

Build

Clone the repository:
```bash
git clone https://github.com/kiracracker/6502-cpu.git
cd 6502-cpu
```
Configure and build the project:
```bash
cmake -S . -B build
cmake --build build
```
Run

Run the executable generated by the build process. Its location depends on your operating system and CMake generator.

Goals

The goal of this project is to build a better understanding of computer architecture and low-level programming by implementing a CPU emulator from the ground up.

Future development will focus on instruction coverage, addressing modes, accurate processor behavior, and testing.
